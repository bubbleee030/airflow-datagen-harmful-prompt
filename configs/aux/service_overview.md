# 範例平台 — 服務概觀（供生成時參考領域詞彙）

這是一份通用的範例文件，用來示範「輔助文件」如何提供領域詞彙。請換成你自己平台的說明。

## 服務項目

1. **對話與工作流前台**：對話介面、工作流設計工具（Workflow Builder）、RAG 知識問答介面
2. **多模型 API 服務**：提供多個開源模型的 API，內含安全代理層（Safety Proxy）
3. **模型微調與評估**：資料生成、模型微調、模型評估

## 常見名詞

- **點數 / 額度**：使用 API 所消耗的計算資源單位
- **補助計畫**：部分使用者透過研究補助計畫取得服務資格
- **計畫代碼**：用於識別補助計畫與計價的代碼，格式如 PRJ-2026-001
- **試用方案**：新使用者可申請的限時免費額度
